# Plugin de Figma

Arma en Figma el sistema de diseño de Konys y las pantallas en alta y baja fidelidad.

1. En Figma de escritorio, crear un archivo vacío.
2. Plugins → Development → Import plugin from manifest… y escoger `manifest.json`.
3. Correr Plugins → Development → Konys Pizza · Sistema de diseño.

Quedan cuatro páginas: portada, sistema de diseño (colores, tipografía, espaciado, íconos y componentes), mockups de alta fidelidad y mockups de baja fidelidad.

El logo y las fotos son provisionales.
